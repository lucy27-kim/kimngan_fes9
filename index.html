私について

ベトナム出身のIT学生です。日本で働く外国人ITエンジニアを目指し、プログラミングの基礎やシステム開発を学んでいます。相手の話をよく聞き、周りと協力しながら、任されたことに責任を持って取り組みます。

IT学生として制作したプログラミング作品

授業やチーム制作で取り組んだ作品です。使用した技術と担当した内容を紹介します。

学生管理システム

Java、JDBC、MySQLを使用したWebシステムです。設計・コーディング・テストを担当し、データベースとの連携を学びました。

Javaクイズアプリ

Java Swingを使ったクイズアプリです。問題と選択肢の表示、正誤判定、スコア表示を実装しました。

ミニタスク管理システム

C言語を使い、クラスメートとチームで制作しました。メンバーと相談して役割を分担し、協力して開発を進めました。
